## Overview

CNode 1 is a frontend prototype workspace using a modern component-driven React stack. The repository is kept intentionally focused on building, iterating, and validating interface ideas.

The repository is maintained by **K. Kishor Kumar** as part of an evolving portfolio of software, AI, IoT and product-engineering experiments.

## Highlights

- React + TypeScript application structure
- Reusable UI primitives and responsive layouts
- Client-side routing, forms and data-ready components
- Development, production build and test scripts

## Technology

React 18 · TypeScript · Vite · Tailwind CSS · shadcn/ui · React Router · TanStack Query · Vitest

## Project Status

**Prototype / active experimentation**

This README intentionally documents the project at the repository level. Implementation details are kept aligned with the codebase as the project evolves.

## Local Development

```bash
git clone https://github.com/Kishordiu/cnode-1.git
cd <project-directory>
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

Run the test suite when available:

```bash
npm run test
```

## Repository Principles

- Keep secrets and local environment files out of source control.

- Keep documentation synchronized with the implementation.
